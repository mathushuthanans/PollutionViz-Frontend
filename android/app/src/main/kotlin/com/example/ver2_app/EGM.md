# ver2_app (Android host package)

## Overview
Generated Flutter Android boilerplate. Holds the single native entry-point activity that hosts the Flutter engine for the app. It contains no app logic; all application code lives in the Dart sources under `lib/`.

## Interface
- `MainActivity` (`MainActivity.kt`): `class MainActivity : FlutterActivity()` in package `com.example.ver2_app`. Empty subclass with no overrides. Referenced by `android:name=".MainActivity"` in `app/src/main/AndroidManifest.xml` as the `MAIN`/`LAUNCHER` activity.
- `io.flutter.plugins.GeneratedPluginRegistrant` (`app/src/main/java/io/flutter/plugins/GeneratedPluginRegistrant.java`): auto-generated by the Flutter tool, gitignored (see `android/.gitignore`), not documented here.

## Invariants
- The package name must match `namespace` and `applicationId` (`com.example.ver2_app`) in `app/build.gradle.kts`, and the manifest's `.MainActivity` reference.
- `MainActivity.kt` is unmodified template code. `GeneratedPluginRegistrant.java` is regenerated by the Flutter tool and must not be edited by hand.

## Side Effects
- None in code. The activity only inherits the default `FlutterActivity` behavior (starting a Flutter engine and rendering the Dart app).

## Verification
- Run: `flutter analyze` and `flutter build apk` from the Flutter project root (`PollutionViz-Frontend`).
