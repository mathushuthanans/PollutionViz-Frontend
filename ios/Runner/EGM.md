# Runner

## Overview
The iOS host application target (`Runner`) that embeds the Flutter engine and
the Dart app from the parent Flutter project. It is generated Flutter platform
boilerplate: the only hand-written native code is a thin `FlutterAppDelegate`
subclass that registers Flutter plugins at launch. UI is entirely Flutter;
the storyboards only provide the launch screen and the Flutter view host.

## Interface
- `AppDelegate.swift`: `@main @objc class AppDelegate: FlutterAppDelegate`. Overrides
  `application(_:didFinishLaunchingWithOptions:)`, calls
  `GeneratedPluginRegistrant.register(with: self)`, then returns
  `super.application(...)`.
- `Runner-Bridging-Header.h`: imports `GeneratedPluginRegistrant.h` so Swift can see the registrant.
- `GeneratedPluginRegistrant.h` / `GeneratedPluginRegistrant.m` (generated, gitignored via
  `Runner/GeneratedPluginRegistrant.*` in `ios/.gitignore`): declares and implements
  `+[GeneratedPluginRegistrant registerWithRegistry:]`. Currently registers
  `GeolocatorPlugin` (`geolocator_apple`), `SharedPreferencesPlugin`
  (`shared_preferences_foundation`) and `WebViewFlutterPlugin`
  (`webview_flutter_wkwebview`).
- `Info.plist`: app metadata. Notable keys: `CFBundleDisplayName` = `Ver2 App`,
  `CFBundleName` = `ver2_app`, `UIMainStoryboardFile` = `Main`,
  `UILaunchStoryboardName` = `LaunchScreen`, `NSLocationWhenInUseUsageDescription`
  (location rationale text), `CFBundleShortVersionString` = `$(FLUTTER_BUILD_NAME)`,
  `CFBundleVersion` = `$(FLUTTER_BUILD_NUMBER)`.
- `Base.lproj/Main.storyboard`, `Base.lproj/LaunchScreen.storyboard`: Interface Builder resources.
- `Assets.xcassets/AppIcon.appiconset`, `Assets.xcassets/LaunchImage.imageset`: asset catalogs
  (icons and launch image; `LaunchImage.imageset/README.md` is Flutter's stock note).

## Invariants
- `GeneratedPluginRegistrant.h`/`.m` are marked "Generated file. Do not edit."; they are
  regenerated by the Flutter tool (for example during `flutter pub get` or `flutter build ios`)
  from the plugins in `pubspec.yaml`. Their plugin list can therefore change without source edits.
- `AppDelegate.didFinishLaunchingWithOptions` must call `GeneratedPluginRegistrant.register(with:)`
  before returning, otherwise plugin method channels are not registered.
- `Info.plist` version values are build-setting placeholders fed from Flutter
  (`FLUTTER_BUILD_NAME`, `FLUTTER_BUILD_NUMBER`), not hard-coded.
- Per `Runner.xcodeproj/project.pbxproj`: bundle id `com.example.ver2App`, iOS deployment
  target 12.0, Swift 5.0.

## Side Effects
- At launch, registers three plugins with the Flutter engine (listed above).
- `NSLocationWhenInUseUsageDescription` makes iOS show a location permission prompt when the
  geolocator plugin requests location access.
- No direct network, disk or database access is performed by code in this directory.

## Verification
- Run: `flutter analyze` (Dart side, from `PollutionViz-Frontend`) and `flutter build ios`
  (requires macOS with Xcode; builds this target). Native unit tests live in `../RunnerTests`
  (placeholder `testExample` only) and run through Xcode.
