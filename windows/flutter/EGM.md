# flutter

## Overview
Flutter tool-managed build glue for the Windows target. `CMakeLists.txt` is marked "should not be edited"; the plugin registrant files are marked "Generated file. Do not edit." and are regenerated by the Flutter tool when plugins change (`flutter pub get`). The `ephemeral/` subdirectory is gitignored and is not documented.

## Interface
- `generated_plugin_registrant.h:RegisterPlugins(flutter::PluginRegistry*)` - declared here, consumed by `../runner/flutter_window.cpp`.
- `generated_plugin_registrant.cc` - implements `RegisterPlugins`; currently registers `GeolocatorWindows` via `GeolocatorWindowsRegisterWithRegistrar`.
- `generated_plugins.cmake` - `FLUTTER_PLUGIN_LIST` (`geolocator_windows`), `FLUTTER_FFI_PLUGIN_LIST` (`jni`), and `PLUGIN_BUNDLED_LIBRARIES`. Each plugin is added from `flutter/ephemeral/.plugin_symlinks/<plugin>/windows` and linked to `${BINARY_NAME}`.
- `CMakeLists.txt` - includes `ephemeral/generated_config.cmake`; defines the `flutter` interface library (links `flutter_windows.dll.lib`), static libraries `flutter_wrapper_plugin` and `flutter_wrapper_app` built from `ephemeral/cpp_client_wrapper`, and the `flutter_assemble` custom target. Publishes `FLUTTER_LIBRARY`, `FLUTTER_ICU_DATA_FILE`, `PROJECT_BUILD_DIR`, `AOT_LIBRARY` to the parent scope for the install step in `../CMakeLists.txt`.

## Invariants
- Do not hand-edit any file here; edits are overwritten on regeneration.
- `generated_plugins.cmake` requires `${BINARY_NAME}` to exist, so it is included after `add_subdirectory("runner")` in `../CMakeLists.txt`.
- `FLUTTER_TARGET_PLATFORM` defaults to `windows-x64` when the Flutter tool does not provide it.
- Everything under `ephemeral/` must exist (generated by the Flutter tool) before CMake configure succeeds.

## Side Effects
- `flutter_assemble` runs the Flutter tool (`tool_backend`) during build to produce the engine library, ICU data, and assets.
- Plugin native libraries are collected into `PLUGIN_BUNDLED_LIBRARIES` and installed next to the executable.

## Verification
- Run from the repo root (`PollutionViz-Frontend`): `flutter build windows` (Windows host required) and `flutter analyze`. Run `flutter pub get` to regenerate files here.
