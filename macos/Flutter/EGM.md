# Flutter (macOS tooling config)

## Overview
Flutter-managed configuration for the macOS runner. `GeneratedPluginRegistrant.swift` is regenerated by the Flutter tool (header: "Generated file. Do not edit."). The sibling `ephemeral/` directory is gitignored (`**/Flutter/ephemeral/`) and is not documented here.

## Interface
- `GeneratedPluginRegistrant.swift:RegisterGeneratedPlugins(registry: FlutterPluginRegistry)` - registers `GeolocatorPlugin` (`geolocator_apple`), `SharedPreferencesPlugin` (`shared_preferences_foundation`), and `WebViewFlutterPlugin` (`webview_flutter_wkwebview`). Called from `../Runner/MainFlutterWindow.swift`.
- `Flutter-Debug.xcconfig` and `Flutter-Release.xcconfig` - each only includes `ephemeral/Flutter-Generated.xcconfig`; consumed by `../Runner/Configs/Debug.xcconfig` and `Release.xcconfig`.

## Invariants
- Do not hand-edit `GeneratedPluginRegistrant.swift`; its plugin list is derived from the Dart dependencies and is rewritten by Flutter tooling (for example `flutter pub get`).
- The xcconfig files depend on `ephemeral/Flutter-Generated.xcconfig`, which only exists after Flutter tooling has run.

## Side Effects
- Plugin registration at app startup exposes location (geolocator), preferences storage, and WebView native handlers to Dart.

## Verification
- Run: `flutter build macos` (or `flutter analyze`) from the Flutter project root, `PollutionViz-Frontend/`.
