# linux Blueprint

## System Overview
Flutter Linux desktop platform host for the app. It is generated Flutter boilerplate with a small amount of project configuration. A CMake build compiles a GTK3 runner executable (`ver2_app`, application ID `com.example.ver2_app`) and links it against the Flutter Linux embedder. The Flutter tool backend builds the Dart code, and `install()` rules assemble a relocatable bundle in `build/linux/<arch>/<mode>/bundle`.

## Local Interface & Invariants
- `CMakeLists.txt` is the only direct file here. It sets `BINARY_NAME` to `ver2_app` and `APPLICATION_ID` to `com.example.ver2_app`.
- `apply_standard_settings(TARGET)` applies C++14, `-Wall -Werror`, and `-O3` plus `NDEBUG` for non-Debug configurations.
- The executable is output to `intermediates_do_not_run/` on purpose. Only the installed bundle copy launches correctly, because resources need fixed relative paths.
- `CMAKE_INSTALL_RPATH` is `$ORIGIN/lib`.
- The default `CMAKE_BUILD_TYPE` is `Debug` when none is given.
- The AOT library (`libapp.so`) is installed only for non-Debug builds.
- The install step wipes the bundle directory and `data/flutter_assets` and copies them fresh each time.
- `.gitignore` excludes `flutter/ephemeral`.

## Subdirectories & System Boundaries
- flutter: [./flutter/EGM.md](./flutter/EGM.md) - Flutter-managed CMake rules and generated plugin registrant. Do not hand-edit.
- runner: [./runner/EGM.md](./runner/EGM.md) - GTK application and window host, with `main`.
- flutter/ephemeral: gitignored and regenerated by the Flutter tool. It has no contract.

## Global Invariants
- Generated files in `flutter/` must not be edited by hand.
- `BINARY_NAME` is defined in the top-level `CMakeLists.txt` only. `runner/CMakeLists.txt` relies on it.
- Warnings are errors in the runner target.

## Global Side Effects
- Builds invoke the Flutter tool (`tool_backend.sh`), which writes under `flutter/ephemeral/` and the project's `build/` directory.
- Native assets from `build/native_assets/linux/` are copied into the bundle's `lib/`.
- The `jni` FFI plugin is listed in `flutter/generated_plugins.cmake`.

## System Verification
- Run from `PollutionViz-Frontend/`: `flutter build linux` and `flutter analyze`. The latter covers Dart only.
