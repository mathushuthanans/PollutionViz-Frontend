# android

## Overview
Android platform folder of the scaffold. It holds `gradlew`, `gradlew.bat`, `local.properties` (SDK paths for another machine), `gradle/wrapper/gradle-wrapper.jar`, and an `app/` module containing only the generated plugin registrant. There are no `build.gradle` files, no `AndroidManifest.xml`, and no `MainActivity`.

## Subdirectories & Boundaries
- app: [./app/EGM.md](./app/EGM.md) - Android app module; only generated `GeneratedPluginRegistrant.java` exists below it.
