# plugins (Android GeneratedPluginRegistrant)

## Overview
Holds the Flutter-tool-generated Android plugin registrant. The file header states "Generated file. Do not edit."; it is rewritten by the Flutter tool from the plugins that support Android.

## Interface
- `GeneratedPluginRegistrant.java`: `public final class io.flutter.plugins.GeneratedPluginRegistrant` (annotated `@Keep`) with `public static void registerWith(@NonNull FlutterEngine flutterEngine)`.
- `registerWith` adds `io.flutter.plugins.pathprovider.PathProviderPlugin` (`path_provider_android`) and `io.flutter.plugins.webviewflutter.WebViewFlutterPlugin` (`webview_flutter_android`) to `flutterEngine.getPlugins()`.

## Invariants
- Each plugin registration is wrapped in its own `try/catch (Exception e)`; a failure is logged via `io.flutter.Log.e` with tag `GeneratedPluginRegistrant` and does not stop the next registration.
- The plugin list is derived from the app's dependencies, so it must be regenerated by the Flutter tool, not hand-edited.

## Side Effects
- Mutates the `FlutterEngine` plugin registry (`flutterEngine.getPlugins().add(...)`).
- Logs registration errors through `io.flutter.Log`.

## Verification
- Run: `flutter build apk` (from a Flutter app root that contains a `pubspec.yaml`; this scaffold has none).
