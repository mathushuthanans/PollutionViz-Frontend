# Flutter (iOS)

## Overview
iOS Flutter configuration folder. It holds the generated `Generated.xcconfig` and `flutter_export_environment.sh` (not source files) plus an `ephemeral/` directory with the LLDB helper.

## Subdirectories & Boundaries
- ephemeral: [./ephemeral/EGM.md](./ephemeral/EGM.md) - Generated LLDB helper script (`flutter_lldb_helper.py`).
